# Code of Conduct

EvidenceRail is intended to support serious technical and governance collaboration around child-safety control evidence.

## Expected conduct

Participants should:

- engage respectfully and professionally;
- critique ideas, schemas, tests, and implementations rather than people;
- avoid publishing personal, confidential, identifying, or child-related information in issues, examples, pull requests, or discussions;
- use synthetic or appropriately de-identified examples;
- disclose material conflicts of interest;
- respect project scope, licensing, and security-reporting boundaries.

## Unacceptable conduct

Harassment, threats, discriminatory abuse, doxxing, deliberate disclosure of sensitive information, or attempts to use project channels to identify or target children are not acceptable.

## Reporting

For security issues, use the private GitHub Security Advisory workflow described in `SECURITY.md`.

For conduct issues, use GitHub's repository reporting or moderation tools, or an appropriate private GitHub channel.

Do not publish sensitive conduct reports as public issues.

## Enforcement

Maintainers may edit or remove content, close discussions, reject contributions, or restrict participation where necessary to protect contributors, users, or project integrity.
