# Changelog

## v0.1.0 — Release Candidate

Initial public-release candidate for EvidenceRail.

Includes:

- Control Evidence Record (CER) schema;
- Review/Outcome Record (ROR) schema;
- trigger and action vocabularies;
- trigger-context schemas;
- positive, negative, and flagship examples;
- Python schema and fixture validation;
- Node validator and hashing helpers;
- static browser reference implementation;
- canonical Michvi schema namespace;
- security, conduct, contribution, and CI scaffolding.

This release does not provide age verification, content moderation, compliance certification, identity verification, platform monitoring, or child-content storage.
